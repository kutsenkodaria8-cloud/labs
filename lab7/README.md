# Lab6: C++ OpenCV

## Вимоги
- Linux (Ubuntu 20.04+) або Windows з MinGW
- Веб-камера

## Встановлення та запуск (Linux)
```
./preinstall.sh
./build.sh
./run.sh
```
## Клавіші (англійська розкладка)
- 0 — нормальний режим
- 1 — інверсія
- 2 — blur
- 3 — canny
- 4 — sobel
- 5 — бінаризація
- 6 — glitch
- 7 — zoom in
- 8 — zoom out
- 9 — малювання прямокутників (ЛКМ)
- o — overlay PNG
- i — інфо (FPS, RGB)
- a/d — переміщення overlay вліво/вправо (тільки в режимі o)
- w/s — переміщення overlay вниз/вверх (тільки в режимі о)
- c — очистити прямокутники
- f — режим детекції облич (Face)
- ESC — вихід

## Архітектура
- `FaceDetector` — клас для детекції облич у фоновому потоці (std::thread + std::mutex)
- `CameraProvider` — захоплення відео з камери
- `FrameProcessor` — застосування фільтрів та FPS
- `KeyProcessor` — обробка клавіатури та режимів
- `Display` — відображення кадру та тексту
